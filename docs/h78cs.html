Why the family's best file scored 0.2778 (owner-report; structure measured here)

DTI = TPw/(TPw+0.2·FPw+0.8·FNw) with a 300 m max-credit kernel charges 0.2 per emitted pixel, so the optimum is binary sparse dots and a dot helps only if its credit exceeds ≈0.2·DTI (0.0556 at 0.2778). The chain H19-5 solid (121,131 px, 0.1922) → D2.8 (44,090 dots on the same lines, 0.2600) → H33 (exact 37,654-dot subset deleting every dot ≤2 px from the catalogue, 0.2778) changed no detector at all — it removed redundant and near-catalogue mass. Beating 0.2778 therefore needs a better ranking of pixels by true-fault probability (credit per dot ≈0.13 → ≈0.16 for ~0.32), validated on hide-and-recover holdout — which is what this lane attempted and, measured below, did not achieve.
