🎯 What is H78-NET?

H78-NET is a new candidate submission that extends H78-A with network-aware context features. While H78-A uses orientation-steered derivative filters, H78-NET adds features that describe each pixel's position relative to the visible fault network topology.

Core Hypothesis

Unmapped faults in the footprint are most likely to occur in structural gaps within the visible fault network.

In the Basin and Range province, faults occur in sub-parallel arrays. When an expert maps faults at 1:250k scale, they may miss:

  • Subtle strands parallel to mapped neighbors but with < 5m scarp
  • Buried faults under alluvial cover but continuing the structural trend
  • Relay ramps connecting en-echelon fault segments
  • Fault tips extending beyond mapped traces
  • Step-overs between parallel fault strands

H78-NET captures these by adding 20 network context features that describe the structural position of each pixel.

🔬 Validation Protocol

H78-NET follows the PARALLEL-RUN PROTOCOL strictly:

1. Leakage Canary

Each feature is tested alone on the holdout set. AUC > 0.90 = leakage until proven otherwise.

Status: PENDING - Will be checked during holdout run

2. Holdout Evaluation

  • Draw: gems57.holdout.buffered_component_draw(seed=20, hide_frac=0.20, buffer_px=3)
  • Evaluator: gems57-pooled-hide-v2 (unmodified)
  • Scoring: Pooled DTI (α=0.2, β=0.8, 300m triangular kernel)
  • CI: 95% paired 20km block bootstrap (1000 draws, seed 520810)
  • Withheld: 11,321 positive pixels (20% of catalogue)

Status: PENDING - Ready to run

3. Uniqueness Check

H78-NET will be checked against all registry rasters:

  • Spearman ρ vs any registry raster must be ≤ 0.90
  • Fraction of dots within 3px of any registry raster must be ≤ 0.70
  • Checked on both score surface and final dots

Status: PENDING - Will be checked after emission

4. Format Validation

The TIF file will be validated to ensure:

  • Single-band float32 GeoTIFF
  • EPSG:32611 CRS
  • 3730 × 3292 pixels
  • Correct geotransform: (100, 0, 243350, 0, -100, 4508550)
  • All finite values, no NaN
  • Values in [0, 1] (binary: exactly 0 or 1)
  • Zeros outside footprint
  • No positives on catalogue

🚀 How to Run H78-NET

Prerequisites:

  • Data restored: bash scripts/restore_data.sh
  • Dependencies installed: pip install -r requirements.txt
  • Registry rasters available: data/registry/*.tif

Step 1: Holdout Evaluation

python scripts/run_holdout_net.py --seed 20 --n-neg 450000

Duration: ~2-4 hours on 2 CPUs, 4 GB RAM

Output: evidence/h78net_holdout_seed20.json

Step 2: Confidence Intervals

python scripts/pooled_ci.py --in evidence/h78net_holdout_seed20.json --out evidence/h78net_pooled_ci_seed20.json

Duration: ~1-2 minutes

Output: evidence/h78net_pooled_ci_seed20.json

Step 3: Build Submission

python scripts/build_submission_net.py --holdout evidence/h78net_holdout_seed20.json --ci evidence/h78net_pooled_ci_seed20.json

Duration: ~3-5 minutes

Outputs:

  • docs/downloads/gems78-h78net-44090dots-*.tif (TIF file)
  • docs/downloads/gems78-h78net-44090dots-*.zip (ZIP file)
  • evidence/h78net_run_card.json (Full run card)
  • docs/data/submission_net.json (Site metadata)

Step 4: Verify TIF

python scripts/verify_tif.py docs/downloads/gems78-h78net-44090dots-*.tif

Checks: All 12 validation criteria

Step 5: Update Site

python scripts/build_site.py

Updates: Home page banner, download links, run card display

⚠️ Important Notes

  1. Holdout ≠ Live: The holdout score measures recovery of withheld mapped faults. Live scoring measures recovery of unmapped faults. They are correlated but not identical.
  2. No Projections: All DTI scores on this page are HOLDOUT-DTI until an organizer receipt is obtained. They are not leaderboard predictions.
  3. Leakage Safety: Network features use only visible catalogue. The holdout draw removes all visible catalogue within 3px of withheld components, so by construction no withheld truth lies within 3px of a visible fault.
  4. Emission Geometry: Uses the same D2.8 → H33 validated geometry: greedy packing at ≥2.8px spacing with 3px flank pruning.
  5. Budget: 44,090 dots matches the live-validated D2.8/H33 scale. This is near the metric's break-even point (0.2 × DTI ≈ 0.056 credit/dot at DTI 0.28).
