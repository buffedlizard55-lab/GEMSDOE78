Implemented exact C-accelerated 300 m submodular greedy dot emitter (src/gems78/_fast_emit.c + emit.submodular_dti_dots) tracking exact per-pixel kernel coverage M_i = max_d K(dist(i,d)) with hard min_dist=2.5 px (realised min_nn=2.8284 px, frac_nn<=1.5 = 0.0), improving strict LOQO HOLDOUT-DTI by +0.0067 over spaced greedy alone.
